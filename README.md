# HTML_assign_3

## Resume Using HTML

This repository contains a personal resume webpage created using HTML only. The project demonstrates how to build a professional-looking resume with structured sections, semantic markup, and embedded media.

## What I did in this repo

- Created a resume page named `Resume.html`
- Added personal information like name, email, phone number, and address
- Included a profile image section
- Wrote a career objective and profile summary
- Added educational qualifications in a table format
- Listed technical skills in categories like programming languages, web technologies, and tools
- Added project experience and achievements
- Included certifications and hobbies/interests
- Added a project demonstration video using an embedded YouTube iframe
- Added contact information and a declaration section

## Files in the repository

- `README.md` – project overview
- `Resume.html` – main resume website
- `src/` – contains supporting assets such as images

## Technologies used

- HTML
- Basic webpage structure and semantic elements

## How to view the project

Open `Resume.html` in a browser to view the resume.

This project was created as an HTML assignment to practice building a resume website using markup and content organization.
